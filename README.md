
# Manual Testing – Tutorial Ninja (Product Compare Module)
📌 Project Overview

This project focuses on manual testing of the Product Compare Module in the Tutorial Ninja e-commerce application.
The objective was to validate the functionality, usability, and reliability of the product comparison feature.

🎯 Scope of Testing

Functional Testing

UI/UX Testing
Positive & Negative Testing
Boundary Value Testing
Regression Testing

🛠️ Features Tested

Product selection for comparison
Adding multiple products to the comparison list
Comparison page display and layout
Removing products from the comparison list
Validation of product details (price, description, availability)

📑 Test Artifacts

Test Scenarios & Test Cases (well-documented with steps and expected results)
Bug Reports (with severity, priority, and reproduction steps)
Test Execution Reports (pass/fail status with screenshots)

🐞 Defects Logged

Incorrect display of product details during comparison
Alignment/UI issues on comparison page
Failure in removing products under certain conditions
✅ Outcome
The testing ensured that the Product Compare Module works as expected with some identified defects that were reported for resolution.
